# Security

**English** · [Português](#segurança)

Report vulnerabilities in this plugin privately through
[GitHub Security Advisories](https://github.com/renatofigueiredods/aws-security-agent-claude/security/advisories/new),
not through public issues.

Vulnerabilities in AWS Security Agent itself or in `awslabs.security-agent-mcp-server` go
to AWS, as described in the
[original power](https://github.com/AWS-Security-Agent/aws-security-agent-kiro-power/blob/main/CONTRIBUTING.md#security-issue-notifications).

Never paste findings, attack scripts or `.security-agent/` content into an issue or PR.

## Segurança

Reporte vulnerabilidades deste plugin de forma privada pelo
[GitHub Security Advisories](https://github.com/renatofigueiredods/aws-security-agent-claude/security/advisories/new),
e não por issue pública.

Vulnerabilidades do próprio AWS Security Agent ou do `awslabs.security-agent-mcp-server`
vão para a AWS, como descrito no
[power original](https://github.com/AWS-Security-Agent/aws-security-agent-kiro-power/blob/main/CONTRIBUTING.md#security-issue-notifications).

Nunca cole findings, scripts de ataque ou conteúdo de `.security-agent/` em issue ou PR.
